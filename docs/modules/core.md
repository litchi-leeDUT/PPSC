# Core 模块约定

> 状态：草案，可直接修改。对应 crate：`ppsc-core`

## 职责

- 定义跨模块稳定 ID、协议版本、任务状态和字节容器。
- 提供不依赖网络、数据库、链 SDK 的领域校验错误。

## 必须遵守

- ID 的编码规则一旦公开，不得在小版本中改变。
- 敏感类型不得实现 `Debug`、`Display`、`Serialize` 或无条件 `Clone`。
- 新增状态时同步补充合法状态迁移表及测试。

## 不负责

- 密码算法、序列化协议、数据库模型和 RPC DTO。

## 测试清单

- ID 字节往返。
- 协议版本兼容判定。
- 每条合法/非法状态迁移。
- 敏感缓冲区清零（在实现可观测测试钩子后）。

## 待确认

- [ ] ID 是否统一使用 32 字节，外部文本表示是否为十六进制。
- [ ] 协议版本的兼容策略。
- [ ] 任务状态是否需要 `Cancelled` 和 `Expired`。
